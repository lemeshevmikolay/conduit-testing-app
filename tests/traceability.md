# Матриця трасування API

Інтеграційні кейси йдуть у навчальному порядку в `api-lifecycle.test.cjs`. Усі API кейси перевіряють лише успішні відповіді; спільна перевірка контракту охоплює HTTP статус, `Content-Type`, `X-Request-Id`, `Access-Control-Expose-Headers` і відповідний `requestId` у JSON.

| № кейсу | API виклик | Очікуваний результат |
| --- | --- | --- |
| 01 | `GET /health` | API та тестова БД готові |
| 02, 10 | `POST /users` | Створено непідтвердженого користувача |
| 03, 11 | `POST /users/verify-email` | Email підтверджено, повернуто token |
| 04, 09 | `POST /users/login` | Повернуто автентифікованого користувача |
| 05 | `GET /user` | Поточний користувач збігається з записом у БД |
| 06 | `PUT /user` | Профільні поля збережено в БД |
| 07 | `POST /users/forgot-password` | Повернуто повідомлення про код відновлення |
| 08 | `POST /users/reset-password` | Пароль змінено, новий hash перевірено |
| 12, 13 | `POST /articles` | Створено статті, автора й теги звірено з БД |
| 14 | `GET /articles` | Глобальний список звірено із записами в БД |
| 15 | `GET /articles?author=…&tag=…` | Результат відповідає фільтрам автора й тегу |
| 16 | `GET /articles/:slug` | Поля статті та автора збігаються з БД |
| 17 | `POST /articles/:slug/comments` | Коментар збережений з правильними автором і статтею |
| 18 | `GET /articles/:slug/comments` | Повернуто створений коментар без email автора |
| 19 | `GET /profiles/:username` | Повернуто профіль і стан підписки |
| 20, 25 | `POST/DELETE /profiles/:username/follow` | Підписку додано й видалено в БД |
| 21 | `GET /articles/feed` | Стрічка містить статтю автора, на якого підписано користувача |
| 22, 24 | `POST/DELETE /articles/:slug/favorite` | Like/unlike змінює стан і зв'язок у БД |
| 23 | `GET /articles?favorited=…` | Повернуто обрану користувачем статтю |
| 26 | `PUT /articles/:slug` | Оновлені поля та slug збережені в БД |
| 27 | `GET /tags` | Повернуті теги існують у БД |
| 28 | `DELETE /articles/:slug/comments/:id` | Коментар видалено з БД |
| 29 | `DELETE /articles/:slug` | Статтю видалено з БД |

E2E покриває ті самі ключові сценарії з боку браузера у `account-and-content.cy.js`, включно з формами, відновленням пароля, лайками й анлайками, сторінкою обраних статей, теговою стрічкою, підпискою та Your Feed.
